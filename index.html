Google Sheets Configuration

Get from Google Cloud Console → APIs & Services → Credentials

From Sheet URL: docs.google.com/spreadsheets/d/SHEET_ID/edit

Setup Instructions:

  1. Go to Google Cloud Console
  2. Create/select a project → Enable Sheets API
  3. Create API Key in Credentials
  4. Create a new Google Sheet
  5. Make sheet public (Share → Anyone with link can view)
  6. Add header row: ID, Title, Description, Mode, Settings, Questions, Created, Count
