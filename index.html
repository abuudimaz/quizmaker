📋 Langkah Setup:

  1. Buka Google Cloud Console
  2. Buat/pilih project → Enable Google Sheets API
  3. Buat API Key di Credentials
  4. Buat Google Sheet baru
  5. Set sheet jadi public (Share → Anyone with link can view)
  6. Tambahkan header: ID, Title, Description, Mode, Settings, Questions, Created, Count
